# Image Processing with Python

A collection of small computer vision projects developed using Python and OpenCV.

## Projects

### 1. Real-Time Face Detection

A webcam-based face detection program using OpenCV and the pretrained Haar Cascade frontal face classifier.

The program detects faces in real time and highlights them with green bounding boxes.

Press ESC to close the webcam window.
